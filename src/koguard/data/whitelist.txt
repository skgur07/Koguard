# Koguard 기본 Whitelist
#
# 여기 등록한 표현과 겹치는 매치 구간만 보호한다. 결과 전체를 통과시키지 않는다.
#
# 대상은 금칙어와 형태가 같지만 의미가 전혀 다른 정상 용법이다. 한국어에서 이런
# 충돌은 대부분 뒤에 붙는 보조용언, 연결어미 또는 복합어 뒷어근으로 구분되므로,
# 낱말이 아니라 그 결합형을 등록한다.
#
# 등록 기준은 "정상 용법이 존재하고 그 결합형 집합이 닫혀 있어 열거할 수 있다"이다.
# 뒤에 오는 말이 열린 집합인 표현(`꺼져` + 임의 용언, `뒤질` + 임의 명사,
# `새끼` + 조사)은 여기서 해결할 수 없다. docs/accuracy-baseline.md에 남은
# 오탐으로 기록한다.
#
# 여기에 없는 결합형은 여전히 탐지된다. 서비스별로 필요한 표현은
# KoguardDictionary.from_sources(whitelist=...) 로 추가한다.
